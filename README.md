# 📖 SermonSlide AI (전통 3대지 설교-PPT 자동 변환기)

목회자가 설교 원고(또는 성경 장·절 약어 표기)만 입력하면, 예배 강단용 16:9 와이드스크린 PPTX를 전자동으로 빌드해 주는 Streamlit 웹 애플리케이션입니다.

## ✨ 주요 기능
1. **전통 3대지 원고 자동 인식**: 표지(제목 및 본문 범위), 서론 성구, 1~3대지 명제, 인용 성구를 감지하여 슬라이드별로 정렬합니다.
2. **성경 장·절 자동 보충**: `요 6:28-29`, `막 9:23` 등 약어와 장·절만 적어도 성경 본문을 자동 조회하여 슬라이드에 반영합니다.
3. **가독성 자동 분할**: 성경 본문이 160자를 초과할 경우 프로젝터/전광판 시인성을 위해 문장 단위로 자동 분할 슬라이드를 생성합니다.
4. **듀얼 테마 지원**: 프로젝터용 라이트 모드(화이트/네이비) 및 LED 전광판용 다크 모드를 지원합니다.

## 🚀 로컬 실행 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 애플리케이션 실행
streamlit run app.py
```

## ☁️ Streamlit Community Cloud 배포 가이드
1. 본 프로젝트의 파일들(`app.py`, `requirements.txt`, `README.md`)을 목사님의 GitHub 레포지토리에 푸시합니다.
2. [share.streamlit.io](https://share.streamlit.io)에 접속하여 GitHub 계정으로 로그인합니다.
3. 해당 레포지토리와 브랜치(`main`), 메인 파일 경로(`app.py`)를 지정하고 **Deploy**를 클릭하면 즉시 웹 주소로 서비스가 배포됩니다.
